# Automated Vehicle Classification System

Final project on computer vision for vehicle type classification.

## Description
This project focuses on building a deep learning-based system to automatically detect and classify vehicle types from images.

## Features
- Vehicle detection and classification from images
- Dataset preprocessing and annotation
- Model training and evaluation

## My Role
- Collected and prepared image dataset
- Annotated data for object detection
- Trained deep learning model
- Evaluated model performance

## Tools
Python, PyTorch, YOLOv5
